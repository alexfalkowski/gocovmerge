# Accepted design

This index records gocovmerge's accepted design choices and support boundaries.
The area files carry the same weight as [AGENTS.md](../../AGENTS.md).

Read the relevant area files before proposing a change or recording a finding
or audit entry. Revisit a decision when the owner asks or new evidence changes
its documented contract or tradeoff.

- [CLI](accepted-design/cli.md) covers input selection, output exclusion, and
  output handling.
- [Coverage merging](accepted-design/coverage-merge.md) covers source identity,
  coverage modes, and block compatibility.
